## 付録B. 画面UIモックアップ（Lo‑Fi）
> 青系ミニマル / ダーク・ライト対応 / 片手操作最適化（親指到達域）

### カラートークン（参考）
- `FG-Primary` #2A66B8（青・主要）
- `FG-Primary-Variant` #1E4E8F
- `FG-Surface` #FFFFFF（ライト） / #121212（ダーク）
- `FG-OnSurface` #0A0A0A（ライト） / #EEEEEE（ダーク）
- `FG-Accent` #4DB6F1
- フォント: システム（Roboto / Noto Sans）

---

### 1) Q1ポップアップ（分入力）
```
┌────────────────────────────────┐
│  Q1. 何分使用しますか？                           │
│  [ 30 ] 分                                        │
│  ─ 数字キーパッド ─                               │
│  1  2  3                                          │
│  4  5  6                                          │
│  7  8  9                                          │
│     0  ←  ✓                                       │
│                                                  │
│  ｷｬﾝｾﾙ                       OK（有効時のみ）       │
└────────────────────────────────┘
```
- 入力: 整数分（1〜1440）。既定値=30
- バリデーション: 0や空欄はOK無効 / 1440超はエラーヒント
- アクセス: Back=キャンセル

**エラーヒント例**: `1〜1440の範囲で入力してください`

---

### 2) Q2ポップアップ（目的入力）
```
┌────────────────────────────────┐
│  Q2. 何のために使用しますか？                     │
│  [ テキスト入力（1〜200字）                 ]     │
│  例: 英語学習 / 論文調査 / 動画編集                 │
│                                                  │
│  ｷｬﾝｾﾙ                       OK（1字以上で有効）    │
└────────────────────────────────┘
```
- テンプレチップ（任意）: [勉強][調査][作業][連絡][休憩]
- 200字超でヒント: `200字以内で入力してください`

---

### 3) Q3ポップアップ（最終確認）
```
┌────────────────────────────────┐
│  Q3.  30分の間、英語学習をするために                 │
│       該当のアプリを開きます。                     │
│       30分後はホームに戻り、クールダウン(30分)を適用│
│       します。同意のうえで開きますか？             │
│                                                  │
│  いいえ                          はい               │
└────────────────────────────────┘
```
- 差し込み: `Q1=〇〇分`, `Q2=××`, `クールダウン=設定値(分)`
- はい=プライマリ（青） / いいえ=アウトライン

---

### 4) 終了ポップアップ（時間到達）
```
┌────────────────────────────────┐
│  使用時間が終了しました。ホームに戻ります。         │
│                                                  │
│                             OK                    │
└────────────────────────────────┘
```
- OKでHOMEアクション実行

### 5) ブロック画面（クールダウン中）
```
┌───────────────────────────────────────────┐
│  🔒 クールダウン中                                   │
│  残り 24:58                                           │
│  目的: 英語学習                                       │
│                                                       │
│  [ 緊急解除 ]   [ 設定 ]                              │
│                                                       │
│  ※クールダウンが終了すると自動で解除されます         │
└───────────────────────────────────────────┘
```
- ステータス: mm:ss更新 / 目的は最新セッションを表示
- ボタン: `緊急解除`（ON時のみ表示）, `設定`
- 背景: 半透明ダークオーバーレイ + ぼかし（任意）

---

### 6) 緊急解除フロー（認証→理由入力）
**a. 認証ダイアログ**
```
┌────────────────────────────┐
│  緊急解除(15分) のため認証してください              │
│  [ 生体認証 ]  または  [ PIN ]                        │
└────────────────────────────┘
```
**b. 理由入力**
```
┌────────────────────────────────┐
│  なぜ今すぐ使う必要がありますか？                   │
│  [ テキスト入力（1〜200字, 必須） ]                 │
│                                                  │
│  ｷｬﾝｾﾙ                       OK                     │
└────────────────────────────────┘
```
- OK時: 一時解除タイマー(15分)開始、ログへ `理由/時刻/認証種別`

### 7) 設定画面（主要セクション）
```
[ 対象アプリ ]  (＋ 追加)
  ├─ Instagram  ─── 有効
  ├─ YouTube     ─── 有効
  └─ X           ─── 有効

[ 既定セッション時間 ]
  30 分   ( － / ＋ )

[ クールダウン時間 ]
  30 分   ( － / ＋ )

[ 緊急解除 ]
  ON  認証: 生体 / PIN
  解除許可時間: 5 / **15** / 30 分

[ ログ / エクスポート ]
  直近セッション一覧 →  エクスポート(CSV)

[ 権限と最適化 ]
  使用状況アクセス | アクセシビリティ | オーバーレイ | 電池最適化除外
```

---

### 8) マイクロインタラクション / 状態
- Q1入力OKボタン: 有効化のフェードイン（100ms）
- ブロック画面の残り時間: 1秒毎に数値のみ更新（レイアウトジャンプ無し）
- 緊急解除完了トースト: `15分間一時解除しました`（2s）
- 解除終了トースト: `一時解除が終了しました。ブロックを再開します`（2s）

---

### 9) アクセシビリティ / エラー状態
- フォーカス順: タイトル→入力→補助テキスト→主要ボタン
- コントラスト: 4.5:1以上、タップ領域48dp以上
- エラー文言は赤系ではなく `FG-Primary-Variant` + アイコンで通知

---

### 10) テキスト仕様（UI反映）
- **Q1**: `Q1. 何分使用しますか？（数字を入力）`
- **Q2**: `Q2. 何のために使用しますか？（自由入力）`
- **Q3**: `Q3. 〇〇分の間（Q1で入力した時間）、××をするために該当のアプリを開きます（Q2で入力した内容）。〇〇分後はホームに戻り、クールダウン（△△分）の間アクセスを制限します。同意のうえで開きますか？（はい/いいえ）`
- **終了**: `使用時間が終了しました。ホームに戻ります。`
- **ブロック**: `クールダウン中です。残り mm:ss`
- **緊急解除理由**: `なぜ今すぐ使う必要がありますか？（自由入力）`

---

### 11) 実装ヒント（Compose想定のUI要素）
- Q1: `OutlinedTextField` + `KeyboardType.Number`, OKは `Button(enabled = input in 1..1440)`
- Q2: `TextField(maxLength=200)`, チップは `AssistChip`
- Q3/終了: `AlertDialog` or 自前フルスクリーン `Dialog`
- ブロック画面: `Type=SYSTEM_ALERT_WINDOW` の独自Activity/ComposeViewでフルスクリーン
- 認証: BiometricPrompt / PINはアプリ内画面
